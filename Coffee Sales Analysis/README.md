☕ Daily Brew Coffee – Business Performance Analysis

📌 Project Overview

This Power BI project analyzes the business performance of Daily Brew Coffee across sales, profitability, customers, products, locations, and order activity. The report is designed as a multi-page interactive dashboard that helps users move from a high-level executive overview to deeper customer and product analysis.

The project demonstrates practical Power BI skills including data modeling, DAX measures, KPI cards, time-based analysis, interactive slicers, drill-friendly visuals, and page navigation.

🎯 Project Objectives

Monitor overall sales, profit, and order performance.

Analyze sales and profit trends over time.

Identify high-performing countries, cities, coffee types, and roast types.

Evaluate customer behavior, including repeat customers and high-value customers.

Compare product performance using sales, quantity, profit, and order metrics.

Provide an interactive report that supports quick business decision-making.

🗂️ Data Model

The Power BI model uses business entities such as:

Orders – transactional sales, quantity, order date, customer ID, and order information

Customers – customer details, city, country, and loyalty information

Products – coffee type, roast type, size, unit price, and product information

Measure Table – centralized DAX measures used across the report

This structure allows customer, product, geographic, and time-based analysis to be connected to the underlying order transactions.
